Context

Use cases were agreed. The language for them wasn't.

In early 2024, HubSpot introduced use cases to help users get value faster from the product — a top-priority initiative tied to making HubSpot easy and fast. The use cases themselves were defined. But the customer-facing messaging for them was not: different teams were describing the same use cases in different ways, with no shared language across Free and Starter surfaces.

I was asked to lead a cross-functional project to fix this — developing a content framework that product designers could apply consistently when building and shipping use case experiences.

The work

A framework, not just a copy doc.

I developed a content framework positioning use cases to resonate with HubSpot's Business Builder persona, along with a Loom walkthrough and strategic rationale to help designers apply it independently. The framework included:

  • Use case copy snippets with design rationale for each
  • Value proposition and benefit snippets for each use case at Free and Starter tiers
  • Guidance for applying snippets consistently across surfaces

Despite challenging stakeholder inputs throughout the process, the work landed well. 120 snippets were added to the shared content library — more than 5× as many as any other individual contributor.

The use cases content framework — copy snippets with design rationale, value prop guidance per tier, and application notes for designers building use case experiences.

Outcomes

Measurable impact on conversion.

The use cases framework shipped as part of the Free and Starter relaunch. Results:

  • Free to Starter CVR improved to 9k net additions
  • Touchless purchase CVR increased 209%
  • 9% increase in influenced signups
  • 120 new copy snippets added to the shared content library
