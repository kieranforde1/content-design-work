## Why build a prototype first? Making the engineering case required something working, not a proposal

Making the case for engineering resource required demonstrating that automated terminology checking was feasible — and how accurate it could be. A written proposal wouldn't be enough. Built a working proof of concept using AI-assisted tools (Lovable, Supabase, HubSpot internal API) to validate the approach before committing engineering time.

## The build: from first version to a tool that runs at scale

The prototype achieved 85%+ term detection rate versus manual audit baseline. A 20-minute manual audit could be completed in under a second.

## Code Orange sprint: using the app to run governance at scale

During a Code Orange quality sprint, used the app to send 22 targeted reports to product owners — demonstrating real operational value from the prototype before the engineering rebuild began.
