## Context: designers didn't know which source to trust

HubSpot's design systems documentation was split across two sources — CANVAS and Storybook — that had diverged over time. Designers working on the same product were using different versions of the truth. Neither source was clearly authoritative.

## The work: auditing and rewriting under tight deadlines

Audited the existing content across both sources, identified conflicts and gaps, and rewrote the content for the new Trellis docs site launch. The work had a hard deadline: the Trellis launch. All content had to be accurate, current, and consistent at launch — no catch-up updates planned.

## Outcomes: a single source of truth, and a Craft with Care award

5,358 homepage impressions and 2,206 content guidelines views since launch. Won the Craft with Care award in Q1 2025. CANVAS and Storybook guidance consolidated into a single source.
